# windows-cursors-collection

# How to install

Follow the "Partially" steps only if you **don't** want to use all the pointers. <br>
If you want to use **all** of the pointers skip and go to the "Total" section.

## Partially

1. Choose the folder with the pointers you want
2. Download it and check if it's in the folder "downloads"
3. Go to start or press win+r and type "main.cpl". Then, press enter. An app window should appear
4. In the top bar, select "pointers"
5. Tap on the text "normal select" and then, on the bottom, the button "browse..."
6. Go to "downloads" or the folder where you put the downloaded folder. Double-click it and select che .cur file with called "normal select". Repeat for al the other pointers (some are .ani and **not** .cur. That is normal, they're the animated pointers)
7. Above, click on "save as..." and name it whatever you like and recongize
8. Click "apply" and then "OK"


## Total

1. Choose the folder with the pointers you want
2. Download it and check if it's in the folder "downloads"
3. Open it and search "installer.inf". Then, double-click it: after some time (seconds/minutes) an app window named "Mouse Properties" should open and the theme applied automatically

Here you are, with your new stylish pointers.

***NOTE:***
On Windows 11, if double-clicking doesn't work, right-click on the file and select "install". The pointers will be in C:\Windows\Cursors\packname.

# How to uninstall

If you don't want the pack anymore, you can deselect or uninstall it. The second one make harder to use again the pack because you will need to reinstall it.

## Deselect

1. Go to start or press win+r and type "main.cpl". Then, press enter. An app window should appear
2. In the top bar, select "pointers"
3. In the "Scheme" section click on the down arrow and a dropdown menu will appear
4. Click on the scheme you want to use
5. On the bottom, click "Apply" and then "OK"


## Uninstall

1. Go to start or press win+r and type "main.cpl". Then, press enter. An app window should appear
2. In the top bar, select "pointers"
3. In the "Scheme" section click "Delete" and select a new one
4. On the bottom, click "Apply" and then "OK"

The scheme will be removed. If you also want to delete the files, go to C:\Windows\Cursors\packname and remove it. <br>
I hope you enjoy your new pointers.
